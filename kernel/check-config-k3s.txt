Pointing it at a config file: the script takes the config path as its first positional
argument ("if [ $# -gt 0 ]; then CONFIG=$1"), or from the CONFIG environment variable.
The wrapper gets in the way, though: cmd/k3s/main.go findDataDir() also scans argv for a
data dir and ends up treating the config path as one, so a bare
`k3s check-config /c/config-7.2.6` tries to unpack the k3s bundle into /c/config-7.2.6/data.
Setting K3S_DATA_DIR makes findDataDir() return early and the positional argument then
only reaches the script. That is what the command above does.

Caveats, same shape as the moby run:

  * The "System", "Limits" and "cgroup hierarchy" sections describe the container this
    ran in on the WSL2 host, not the kernel being checked. The swap warning and the
    iptables "unknown version" line belong to that environment.
  * The "modprobe: can't change directory to /lib/modules" line is the script trying to
    load the `configs` module to get /proc/config.gz. It did not need to: we gave it the
    config file directly.
  * Version gates come from `uname -r` (host 6.6.x, not 7.2.6). All gates are for 4.x and
    older, so the same branches run either way.
  * It ran under riscv64 emulation (binfmt/QEMU) because the binary is riscv64. It only
    greps a text file, so emulation does not affect the verdict.

STATUS: pass.

Missing items and whether they matter here:

  * CONFIG_RT_GROUP_SCHED: left out on purpose. Documentation/admin-guide/cgroup-v2.rst
    (line 1109 in 7.2.6) says that with RT_GROUP_SCHED enabled, the cgroup v2 cpu
    controller can only be enabled when all realtime processes are in the root cgroup.
    We are cgroup v2 only, and nothing here needs realtime bandwidth control.
  * CONFIG_CRYPTO_GHASH: renamed, see the moby notes. GHASH is present via
    CONFIG_CRYPTO_LIB_GF128HASH=y.
  * CONFIG_INET_XFRM_MODE_TRANSPORT: the symbol does not exist anywhere in the 7.2.6
    tree (grep over all Kconfig files returns nothing); it was removed upstream years
    ago. Only relevant to encrypted overlay networks in any case.
